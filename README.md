# PCA---to---neural---network---from---scratch
Implement PCA and a simple neural network from scratch to illustrate the linear algebra foundations of modern machine learning.

## PCA to Neural Network: A Linear Algebra Perspective

## Motivation
Many practitioners use PCA and neural networks without fully understanding their linear algebraic connection.
This project bridges that gap by implementing both from scratch.

## Key insight
PCA can be viewed as a single-layer linear neural network without bias or activation.
Neural networks generalize PCA by learning representations through gradient-based optimization and non-linearity.

## Implementation
- PCA from scratch using covariance matrix eigen-decomposition
- Modular linear layer and activation functions
- Manual backpropagation using matrix calculus
- Gradient descent optimization
